# The Inheritance

A 12–18 minute presentation and class game on Max Weber's *The Protestant Ethic and the Spirit of Capitalism* (Kalberg's introduction and Chapter 1).

The class plays one family, the Ashworths, across four centuries (1563, 1655, 1748, 2026) and votes on each generation's choice. A family ledger records what each Ashworth did and why, and the "why" column secularizes as you go. Four discussion questions sit between generations.

## Controls
- Right arrow / Space / clicker: next (reveals one line at a time first). Left arrow: back.
- A, B, C: pick an option on choice slides (or click).
- N: speaker notes with timings and page references.
- S: short version (skips 3 optional slides, about 12–14 minutes).
- F: full screen.

## Put it online
Upload `index.html` to a public GitHub repo, then Settings → Pages → Deploy from a branch → main → / (root). It also works by opening `index.html` directly.
